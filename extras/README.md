# extras: هر چیزی که همراهِ زمزمه است، ولی زمزمه نیست

اپ در `app/` است و ابزارِ بیلد و تست در `tools/`. هر چیزِ دیگری اینجاست: سند،
یادداشت، عکس، نمونه‌ی تنظیم، و یک پلاگین که به خودِ اپ ربطی ندارد.

قاعده‌ی ساده: **اگر فایلی از یک چک‌اوتِ تازه اجرا می‌شود و کد را صدا می‌زند، جایش
اینجا نیست.** نوشته درباره‌ی کد می‌آید اینجا؛ برنامه‌ای که کد را دست می‌زند می‌ماند
در `tools/`.

## چه چیزی کجاست

| مسیر | چیست |
|------|------|
| `extras/docs/dev-notes/` | یادداشت‌های مهندسی. نقشه‌ی خونه‌تکونی، نقشه‌ی عمق، گزارش باگ، نقشه‌ی پورت ویندوز |
| `extras/docs/dev-notes/deep/` | سندِ هر واحدِ عمیق‌سازی، D1 تا D7 |
| `extras/docs/dev-notes/queue-plan.md` | نقشه‌ی صف تکه‌ها، پیش از دست زدن به کد |
| `extras/docs/img/` | عکس‌های ریدمی. دستی گرفته نشده‌اند: `zemzeme --uishot extras/docs/img` |
| `extras/setup/` | نمونه‌ی تنظیمِ بیرونی. امروز فقط رولِ Karabiner |
| `extras/claude-plugin/` | پلاگینِ Claude Code برای رونویسیِ دسته‌ای. اپ به آن بند نیست و آن هم به اپ |

## چه چیزی اینجا نیست، و چرا

- **`CONTEXT.md` در ریشه ماند.** واژه‌نامه‌ی دامنه است و هر سشن سرِ شروع می‌خواندش.
  فایلی که ریپو قانونِ خودش اعلامش می‌کند، کنارِ کد می‌ماند.
- **`README.md` و `README.en.md` و `LICENSE` در ریشه ماندند.** گیت‌هاب ریدمیِ ریشه
  را رندر می‌کند و پروانه جایش همان‌جاست.
- **`tools/fixtures/` جابه‌جا نشد، هر دو نیمش.** نیمِ `read-aloud` در
  `tools/seg_test.m` هاردکد است، پس جابه‌جایی‌اش تغییرِ کد است و بی کامپایلر
  اثبات‌شدنی نیست. و بردنِ نیمِ `ai-pass` به‌تنهایی، جفتِ فیکسچرها را دو تکه می‌کرد،
  که از ماندنشان بدتر است.
- **`app/prompts/` و `app/fonts/` سرِ ران‌تایم خوانده می‌شوند** (`ZRes` و
  `ZRegisterFonts`) و `.readable/` برندکیت است. هر سه خطِ سرخ‌اند.

## گاردش

`tools/paths_test.sh` پیشوندِ `extras/` را می‌شناسد. یعنی هر مسیری که در متن‌های
این پوشه اسمش بیاید و وجود نداشته باشد، قرمز می‌شود. بی کامپایلر و بی مک هم
اجرا می‌شود:

```bash
bash tools/paths_test.sh
```
