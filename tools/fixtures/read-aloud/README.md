# متن‌های خواندنی برای تست e2e

هر فایل یک متن است که با صدای بلند خوانده و ضبط می‌شود. چون متن از قبل معلوم است،
خروجی رونویسی را می‌شود کلمه‌به‌کلمه با آن سنجید: این تنها راهی است که «هیچ کلمه‌ای
گم نشد» یک عدد باشد نه یک حس.

ضبط، مستقیم از همان میکروفنی که اپ استفاده می‌کند و بدون باز کردن سشن دیکته:

    /Applications/Zemzeme.app/Contents/MacOS/zemzeme --micdump take-01.raw 90

عدد آخر ثانیه است. خروجی PCM خام است: s16le، مونو، ۱۶ کیلوهرتز. همان چیزی که
`--selftest` می‌خورد، پس تست e2e بی‌میکروفن و تکرارپذیر می‌شود.

نام فایل ضبط باید هم‌نام متن باشد (`01-bi-vaghfe.raw` کنار `01-bi-vaghfe.txt`)
تا هارنس خودش جفتشان کند.

هر متن یک چیز را می‌سنجد:

| فایل | چه چیزی را می‌سنجد | چطور بخوان |
|---|---|---|
| ۰۱ | برش وقتی سکوتی در کار نیست | بی‌وقفه، تندتر از معمول، بی مکث |
| ۰۲ | اصطلاح انگلیسی وسط فارسی | عادی، انگلیسی‌ها را همان‌طور که همیشه می‌گویی |
| ۰۳ | مکث‌های فکر کردن | جای هر «…» دو سه ثانیه واقعا مکث کن |
| ۰۴ | حساسیت بالای میکروفن (بتا) | پچ‌پچ، از فاصله‌ی معمول |
| ۰۵ | عدد و تاریخ | عادی. پاس هوش مصنوعی حق ندارد این‌ها را عوض کند |
