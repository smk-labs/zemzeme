# harf (حرف)

دیکته فارسی با کیفیت گوگل، روی مک، با یه دابل‌تپ. حرف می‌زنی، زنده می‌نویسه، تهش یه کپی تمیز می‌گیری.

## چطور کار می‌کنه

یه صفحه محلی توی کروم باز می‌شه که از موتور تشخیص گفتار خود گوگل (Web Speech API) استفاده می‌کنه. صدا می‌ره سرور گوگل، متن زنده برمی‌گرده. هیچ اکانت و کلید و پولی لازم نیست.

- `index.html`: صفحه دیکته. فارسی و انگلیسی، متن زنده، ویرایش دستی، تثبیت با Enter.
- `serve.py`: سرور پایتون استاندارد روی `127.0.0.1:17635`. تکه‌های قطعی هر سشن رو توی `sessions/` ذخیره می‌کنه که هیچی گم نشه.
- شورتکات: دابل‌تپ Command راست (Karabiner، فایل `google-dictation.json` توی `assets/complex_modifications`). تپ تنها هیچی نمی‌فرسته که توی ریموت دسکتاپ کلید ویندوز نخوره.

## راه‌اندازی

1. رول «Google Dictation (Web Speech)» رو توی Karabiner-Elements فعال کن (Complex Modifications، بعد Add rule).
2. بار اول اجازه میکروفن رو به کروم بده.

اجرای دستی بدون شورتکات:

```
python3 serve.py &
open -na "Google Chrome" --args --app=http://127.0.0.1:17635
```

## کلیدها

Space توقف و ادامه. Enter تثبیت متن خاکستری. C پاک کردن. L تغییر زبان. Esc کپی همه و بستن.
