# زمزمه (Zemzeme)

دیکته فارسی با کیفیت گوگل، شناور روی هر اپ مک، حتی فول‌اسکرین. دابل‌تپ Command راست، حرف بزن: متن قطعی همان لحظه سر کرسر می‌نشیند و نوار شناور فقط چند کلمه خاکستری آخر را نشان می‌دهد. Esc یعنی پایان: باقی‌مانده درج می‌شود و کل متن یک بار در کلیپ‌بورد می‌ماند.

## اجزا

- `Zemzeme.app` (سورس در `app/Sources-objc/`): اپ منوبار بدون هیچ وابستگی. پنل `NSPanel` بدون گرفتن فوکس، روی همه Space ها (`canJoinAllSpaces + fullScreenAuxiliary`).
- موتور ۱ «گوگل مستقیم»: اتصال به `speech-api/full-duplex/v1` با کلید عمومی Chromium، صدای `l16@16kHz`، پارسر protobuf دستی.
- موتور ۲ «صفحه کروم» (فال‌بک): همان `index.html` + `serve.py` با کانال SSE (`/events`، `/live`، `/alive`). کلید مرد؟ از منو سوییچ کن.
- سوپروایزر (هر دو موتور): backoff نمایی تا ۵ ثانیه، تسلیم بعد از ۸ چرخه بی‌نتیجه (چرخه بی‌صدا حساب نمی‌شود)، واچ‌داگ ۱۲ ثانیه، salvage قبل از هر ری‌استارت، چرخش سشن ~۴٫۵ دقیقه با بافر صدا.
- درج: تایپ مستقیم (پیش‌فرض) یا پیست تکه‌ای transient با برگرداندن کلیپ‌بورد (پیش‌فرض Windows App). تعویض اپ جلویی درج را قفل می‌کند؛ دکمه «مقصد همینجا» صف را همان‌جا خالی می‌کند.
- شورتکات: Karabiner، دابل‌تپ Command راست با ترفند lazy، اکشن: `open -g 'zemzeme://toggle'`. هاتکی داخلی آزمایشی هم در منو هست.

## راه‌اندازی (یک بار)

1. `bash app/build.sh`
2. `open Zemzeme.app` و اجازه Accessibility (برای درج).
3. اولین شروع دیکته: اجازه میکروفن.

## چرا ObjC؟

CLT فعلی (swiftlang-6.2.0.19.9) با ماژول‌های همه SDK های موجود ناسازگار است؛ حتی `import Foundation` کامپایل نمی‌شود. پورت سوئیفت کامل در `app/swift-port/` است؛ بعد از تعمیر CLT قابل بیلد:

```
sudo rm -rf /Library/Developer/CommandLineTools && xcode-select --install
```

## پاس ویرایش

هر تکه قطعی فارسی قبل از نشستن سر کرسر بی‌سروصدا تمیز می‌شود؛ معنا هیچ‌وقت عوض نمی‌شود و `sessions/` همیشه خام می‌ماند.

- درست می‌شود: نیم‌فاصله با تایید دیکشنری («می شود» ← «می‌شود»)، ارقام فارسی (بدون شکستن ۲.۵ و ۱۲:۳۰ و main.py)، یکدست‌سازی حروف عربی، فاصله‌گذاری علائم، نقطه/ویرگول/علامت سوال با مدل کوچک آفلاین، جای خالی مد با تایید دیکشنری («امدند» ← «آمدند»).
- عمدا دست نمی‌خورد: وام‌واژه و محاوره (پلاگین، اونجا، چیکارا)، خطای شنیداری (اکاسی/عکاسی)، هر بازنویسی. هیچ LLM مولدی در کار نیست (arXiv 2512.17247: LLM خام خطای STT فارسی را ~۲ برابر می‌کند).
- اجزا: دیمن گرم `app/py/polish.py` روی پورت ۱۷۶۳۶ (piraye + دیکشنری lilak از راه spylls + نقطه‌گذاری ONNX int8، مدل چندزبانه xlm-roberta چون parsbert گیت‌دار بود). اپ خودش بالا می‌آوردش. سقف هر تکه ۳۰۰ms؛ دیر شد همان خام می‌نشیند و دیگر عوض نمی‌شود. تکه تمام‌لاتین و سشن انگلیسی کلا رد می‌شوند.
- راه‌اندازی یک‌باره: `bash app/py/setup.sh` (دانلود ~۱٫۱ گیگ؛ بعدش کاملا آفلاین). تست طلایی: `python3 tools/polish_test.py`. تاگل: منوی زمزمه، «پاس ویرایش فارسی». جفت قبل/بعد هر تکه در `polish.log`.

## استرس‌تست کلید

`tools/stress_test.sh`: سه سشن ۵ دقیقه‌ای پشت هم با پیس ریل‌تایم. اجرای 2026-07-24: PASS (هر سه سشن تا ثانیه ~۲۹۲ زنده، HTTP 200، بدون throttle). هر وقت به کلید شک کردی دوباره بزنش.

## داده

`sessions/` هر تکه قطعی روی دیسک (وب و اپ، همیشه خام)، `app.log` لاگ اپ، `log.txt` لاگ صفحه وب، `polish.log` جفت قبل/بعد پاس ویرایش.
